## 1.7.8 - 2026-10-12

本版修复覆盖安装时「必须先去托盘退出」的卡死体验。其余行为与 1.7.7 一致：仍基于上游 `v1.7.6`，并保留 fork 的 Chat Completions 补丁。

### 修复

- 覆盖安装不再必须手动退出 Codex++：安装器等待 10 秒后会请求正在运行的 Codex++ 正常退出，再给 30 秒清理时间。
  主程序收到请求后走与托盘「退出程序」完全相同的路径退出：先恢复系统浏览器，再清理后台服务。
- 只有自动退出失败时才回退到手动提示，提示文案写明了 Windows 11 隐藏图标（任务栏右下角 `^`）里的位置。

### 保持不变

- 不使用 taskkill，不强制结束进程。
- 继续携带 fork 补丁：Chat Completions 上游的明文 `encrypted_content` agent payload 按原顺序透传为文本；`multiAgentVersion: v2` 的自定义模型显示 `ultra`；Chat 方言收到 `ultra` 时兜底映射为 `max`（OpenRouter 为 `xhigh`）。

### 安装

- Windows：`CodexPlusPlus-1.7.8-windows-x64-setup.exe`，或免安装的 `CodexPlusPlus-1.7.8-windows-x64.zip`。
- 安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。
- 本 fork 没有 Apple 签名与公证凭据，不提供 macOS 安装包。

### 升级提示

- 从 1.7.7 或更早版本升级到本版时，正在运行的旧版本不认识 `--quit-for-install`，所以这一次仍需手动从托盘退出一次；装上本版之后，再往后的版本升级即可自动完成。
- 应用内“检查更新”目前仍指向官方仓库，不会把本 fork 的 Release 当作更新来源；升级请从本 Release 页面下载。
