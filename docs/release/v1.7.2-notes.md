# 1.7.2 - 2026-10-09

本版修复 Codex 多代理消息在 Chat Completions 上游被拒绝的问题。

- 修复 `unsupported_encrypted_agent_content`：当 Chat Completions 上游收到 `multi_agent v2` 的明文 `encrypted_content` agent payload 时，按原文顺序转换为 Chat 文本，不再直接拒绝。
- 保留安全边界：无法在 Chat 协议中表达的 opaque 加密内容和独立 `encrypted_content` 项仍会明确报错，不会静默丢弃或伪装成明文。
- 新增回归覆盖：验证 `agent_message` 中 header 与 payload 的顺序、opaque 内容拒绝，以及拒绝发生在请求发往 Chat 上游之前。
- 适用于只能使用 Chat Completions 协议、无法切换到 Responses 上游的场景。
