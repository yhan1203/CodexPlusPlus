## 1.7.7 - 2026-10-11

基于上游 Codex++ `v1.7.6` 的 fork 构建，面向只能使用 Chat Completions 协议、无法切换到 Responses 上游的场景。

### 修复

- 修复多代理 v2 任务投递失败：

  `unsupported_encrypted_agent_content: Chat Completions 上游无法处理加密的 agent 消息内容，请使用支持该协议的 Responses 上游`

  `agent_message.content[]` 里的明文 `encrypted_content` payload 现在按原顺序转换为 Chat 文本转发，不再直接拒绝。
- `multiAgentVersion: v2` 的自定义模型会显示 `ultra` 推理档位；Chat Completions 方言收到 `ultra` 时按上游能力兜底映射为 `max`（OpenRouter 为 `xhigh`），不会把 `ultra` 原样发给不支持该字段的上游。

### 安全边界

- 无法在 Chat 协议中表达的 opaque 加密内容继续明确报错，不会静默丢弃或伪装成明文。
- 顶层独立 `{"type":"encrypted_content"}` 项继续明确报错。
- Responses 上游路径不参与转换，始终原样透传。

### 同步自上游 1.7.6

Claude Code 动态汉化管理、本地 SenseVoiceSmall INT8 语音转写、纯 API provider 鉴权 401 修复、插件下载代理继承、Fast 按供应商逐模型声明、`web_search` 的 `input` 别名、原生搜索拦截与压缩历史处理加固。

### 安装

- Windows：`CodexPlusPlus-1.7.7-windows-x64-setup.exe`，或免安装的 `CodexPlusPlus-1.7.7-windows-x64.zip`。
- 安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。
- 本 fork 没有 Apple 签名与公证凭据，不提供 macOS 安装包。

### 注意

- 应用内“检查更新”目前仍指向官方仓库，不会把本 fork 的 Release 当作更新来源；升级请从本 Release 页面下载。
- 上游 PR #2425 仍未合并，官方版本对 `encrypted_content` 依然一律拒绝；官方修复前请继续使用本 fork 构建。
